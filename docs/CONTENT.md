# 글 관리

- 콘텐츠 원본은 `content/posts/*.mdx` 한 곳에서 관리합니다.
- 글 제목·요약·태그는 목록과 상세 페이지에서 공유합니다.
- 비공개 회사 정보는 포함하지 않습니다. 작성자가 원문 그대로 이관하도록 승인한 공개 티스토리 글은 출처와 발행일을 보존합니다.
- 적용 사례로 단정하지 않고 일반 원리와 예시의 전제·한계를 설명합니다.
- 실측하지 않은 성능이나 검증하지 않은 실행 결과를 추가하지 않습니다.
- 참고한 기술 문서는 본문에서 연결합니다.
- 공개 글에는 작성자가 정한 `publishedAt` 날짜를 기록합니다. 날짜를 정하지 않은 초안은 `Draft`로 관리합니다.
- MDX는 신뢰하는 작성자만 편집하며, import/export와 이벤트 핸들러를 사용하지 않습니다.

- 글 목록은 `publishedAt` 최신순으로 정렬합니다. 티스토리 이관 글의 원문 발행일은 그대로 보존합니다.
- 코딩테스트 카테고리와 코딩테스트 회고는 이관하지 않습니다.

## 안내 박스

GitHub 형식의 `> [!NOTE]`, `> [!WARNING]`을 사용하면 종류별 색상으로 표시합니다. Note·Tip·Important·Warning·Caution을 지원하며, 기존 `> **Note**` 표기도 그대로 사용할 수 있습니다. 일반 인용문은 회색으로 표시합니다.

```md
> [!NOTE]
> 참고할 내용을 작성합니다.

> [!WARNING]
> 주의할 내용을 작성합니다.
```
