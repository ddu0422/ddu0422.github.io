## data.sql 파일 생성 및 데이터 입력

```bash
resources
ㄴdata.sql # 파일 생성
```

```sql
insert into climbing_park (name) values ('이름');
```

 

## application.yaml 설정 파일 변경

```bash
spring:
  h2:
    console:
      enabled: true
  datasource:
    driver-class-name: org.h2.Driver
    url: jdbc:h2:mem:local
    username: svc_local
  jpa:
    defer-datasource-initialization: true # 추가
```
