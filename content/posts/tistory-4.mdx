> 해당 글은 Mac OS, IntelliJ Ultimate기준으로 작성되었습니다.

 

1. Projects를 선택 후 **New Project**를 클릭합니다.

 

![원문 이미지 4](/images/tistory/4-1-033f720ac92f.png)

 

2. Spring Initializr를 선택 후 **원하는 세팅**으로 설정합니다.

 

![원문 이미지 4](/images/tistory/4-2-ebb5eed4c1b2.png)

 

3. 초기에 사용할 library를 선택합니다.

Web Application을 개발하기 위해 **Spring Web, MySQL, Spring Data JPA, Lombok**을 추가했습니다.

**H2**는 Test Code 작성할 때 사용하기 위해 추가했습니다.

 

![원문 이미지 4](/images/tistory/4-3-73d7798222c9.png)

 

4. Lombok을 사용하려면 Plugin을 설치해야 합니다.

**IntelliJ IDEA &gt; Preferences를 클릭**하거나 **command(⌘) + ; 단축키**를 사용하여 아래 창을 엽니다.

4-1. 검색 창(command(⌘) + F)에 Plugins를 검색합니다.

4-2. Plugins를 선택합니다.

4-3. Marketplace를 선택합니다. (이미 설치되어 있어 installed가 선택된 모습입니다.)

4-4. lombok을 검색합니다.

4-5. install 합니다.

 

![원문 이미지 4](/images/tistory/4-4-5dc1a46fa034.png)

 

5. View 없이 확인하기 위해 **RestController**를 이용합니다.

브라우저에서 확인하기 위해 **GetMapping**을 이용하여 메서드를 작성합니다.

 

![원문 이미지 4](/images/tistory/4-5-2909d27a3b7a.png)

 

6. Application으로 이동하여 **왼쪽에 화살표를 클릭하여 Run**을 누르거나 **Control(^) + Shift(⇧) + R 단축키**를 사용하여 서버를 실행합니다.

기본 포트는 **8080**이므로 main &gt; resources &gt; application.properties (혹은 application.yaml)에서 <strong>server.port=[원하는 포트 번호]</strong>를 이용하여 포트를 변경할 수 있습니다.

 

![원문 이미지 4](/images/tistory/4-6-b96d076d7201.png)

 

7. 브라우저를 실행 후 http://localhost:8080 (설정한 포트 번호)에 접속하여 **Hello Spring Boot**(작성한 문자열)가 나오는지 확인합니다! 😄

 

![원문 이미지 4](/images/tistory/4-7-49757a010e13.png)
